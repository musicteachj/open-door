1Screen 09: Approvals (Phase 5)

Marcus Bell's Approvals page, full width with no right rail. Each waiting request is a card: who, what, how much, what they'll have left, when it was sent, and who else on the team is off those days. The page states facts only and never suggests a decision. Approve and Deny carry equal weight: both are secondary buttons on the card, and each opens the alert dialog from screen 08, with its full-window scrim and a primary confirm button. Coming up and Recent decisions reuse the screen 08 request row, with the person added. desktop-default is live: approve or deny either request, add a note, and watch the nav count, the lists, the toast, and focus update. The component library is in components.
