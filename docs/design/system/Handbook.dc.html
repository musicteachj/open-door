1Screen 06: Handbook (Phase 3)

The section list is laid out like a table of contents. Each row shows the number, title, who it applies to, and when it was last updated. In the list, "Applies to you" marks only sections with a restricted audience (a state, an employment type, or a location) that covers you. Rows for everyone carry no marker, so for Priya only CA-3.4 and CA-4.3 are marked. Section pages, search results, and the panel show the marker, yes or no, on every section. Section pages keep the body to the 760 px reading measure, at 18/28. A slim chapter navigator sits beside the body and stays in place as you scroll. A cited passage is set on the primary tint with a "Cited passage" label, a quote icon, and a slim cinnamon bar on its left edge, which keeps it distinct from hover and selected states. Color isn't the only signal. Arriving from a citation scrolls the page to the passage and moves focus to it. The passage is a region labeled "Cited passage", so a screen reader announces that label first. Rows are plain links in the Tab order with the visible focus ring, as in the directory. Search results list sections that apply to you first, then by relevance. On no results, "Ask the assistant" opens Ask with the search text in the composer, not sent. "Clear highlight" removes ?passage from the URL without adding a history entry. Every frame works: search, the Show filter, rows, back links, state rules, and Clear highlight. 1a can be viewed as Priya or Mateo with the liveAs setting in Tweaks.
