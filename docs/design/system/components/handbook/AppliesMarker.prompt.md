AppliesMarker sits beside an ApplicabilityBadge. In the section list show only the yes marker, and only on sections with a restricted audience (a state, an employment type, or a location) that covers the person; rows for everyone and rows that don't apply stay unmarked. On section pages, search results, and the passage panel show the marker, yes or no, on every section.

~~~jsx
<AppliesMarker applies />
<AppliesMarker applies={false} />
~~~
